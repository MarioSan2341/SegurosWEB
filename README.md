# ATCH Tornel Asesores

Sitio web de asesoría y mediación de seguros. Slogan: **Hablemos de seguros**.

## Cómo correrlo

```bash
npm install
npm run dev
```

Abre la URL de Vite, por lo general `http://localhost:5173`.

## Dónde está la información del cliente

- Marca, oficina, WhatsApp, correos y redes: `src/data/brand.ts`
- Productos, FAQs y aseguradoras: `src/data/content.ts`
